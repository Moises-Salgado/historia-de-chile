# Historia de Chile · Segundo cerebro

Este vault es la **única fuente de contenido** del sitio web. Cada nota es un nodo del grafo; cada `[[enlace]]`, una conexión. Abre la vista de grafo con `Ctrl + G`.

> [!tip] Cómo se usa
> 1. Escribe o corrige notas aquí, siguiendo [[Guía de contenido]].
> 2. En la carpeta del proyecto ejecuta `npm run build`.
> 3. Abre `site/index.html`: la web ya muestra los cambios.
